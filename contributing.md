# Contributing to easy-django 🧱

Thank you for considering contributing to **easy-django**! We welcome improvements, new features, bug fixes, documentation updates, and suggestions.

---

## 🛠 How to Contribute

### 1. Fork the Repo
Create your own fork of the repo and clone it locally.

```bash
git clone https://github.com/skrindra/easy-django.git
cd easy-django
```

### 2. Create a New Branch
Use a descriptive branch name:
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Changes
- Follow PEP8 style and keep code modular
- Write meaningful commit messages
- Include docstrings and inline comments when needed

### 4. Run Tests
Make sure your changes don’t break existing code.
```bash
python manage.py test
```

### 5. Push and Submit a PR
```bash
git push origin feature/your-feature-name
```
Then open a **Pull Request** on GitHub against the `main` branch.

---

## ✅ What to Include in a PR
- Clear summary of the problem and solution
- Tests for any new functionality
- Update to `README.md` or `setup.py` if relevant

---

## 🧪 Testing Guidelines
- Add unit tests to the `tests/` directory
- Use Django’s `TestCase` or `pytest`
- Follow the naming pattern: `test_<entity>_<action>.py`

---

## 💬 Need Help?
Open an [Issue](https://github.com/skrindra/easy-django/issues) with your question.
